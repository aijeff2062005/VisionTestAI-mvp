Nhờ cấp API token cho Vision Agent

Nhờ DevOps hỗ trợ cấu hình xác thực để Vision Agent gửi XML HIS lên backend production QY.

  1. Dùng tài khoản dịch vụ riêng qy-xml-integration@example.com trên site QY production; nếu chưa có thì tạo theo lệnh bên dưới. Không dùng tài khoản cá nhân hoặc Administrator.
  2. Cấp role được endpoint nhận XML cho phép: Nursing User, Physician hoặc Healthcare Administrator. Ưu tiên role ít quyền nhất theo chính sách bệnh viện; không cấp System Manager nếu không cần.
  3. Chạy các lệnh dưới đây trên server production QY để kiểm tra tài khoản và phát hành token mới.

Mở console đúng site production:

docker exec -it visiontestai-frappe-backend bash -lc \
"cd /home/frappe/frappe-bench && bench --site qdymd.vision.primetek.ai console"

Nếu tài khoản chưa tồn tại, chạy trong Frappe console. DevOps cần thay email nếu tổ chức dùng địa chỉ dịch vụ khác và xác nhận role trước khi tạo:

email = "qy-xml-integration@example.com"
if not frappe.db.exists("User", email):
    user = frappe.get_doc({
        "doctype": "User",
        "email": email,
        "first_name": "QY XML Integration",
        "enabled": 1,
        "user_type": "System User",
        "send_welcome_email": 0,
        "roles": [{"role": "Nursing User"}],
    })
    user.insert(ignore_permissions=True)
    frappe.db.commit()
    print("Tài khoản tích hợp đã được tạo")
else:
    print("Tài khoản đã tồn tại; không tạo trùng")

Trong Frappe console (dòng nhắc In [ ]:), kiểm tra user và role:

email = "qy-xml-integration@example.com"
user = frappe.get_doc("User", email)
print({"email": user.name, "enabled": user.enabled,
       "roles": [row.role for row in user.roles]})

Nếu account đang bật và role đã được duyệt, chạy đoạn này để phát hành token:

user.api_key = frappe.generate_hash(length=15)
api_secret = frappe.generate_hash(length=30)
user.api_secret = api_secret
user.save(ignore_permissions=True)
frappe.db.commit()
print(f"token {user.api_key}:{api_secret}")

Token tạo mới sẽ thay token hiện tại của user này. Kiểm tra trước xem credential cũ có đang được nơi khác dùng không.

Nhờ gửi lại cho mình qua Disroot Bin:
1) API token theo định dạng token API_KEY:API_SECRET; 2) email tài khoản dịch vụ đã cấp quyền.

Vision Agent sẽ kết nối tới backend production QY: https://qdymd.vision.primetek.ai.

Token vừa xuất hiện trong chat, vì vậy không dùng lại; hãy phát hành token mới. Vui lòng đặt thời hạn tự xóa ngắn cho Bin nếu có thể. Không gửi token qua chat thường, email, ticket hoặc ảnh chụp. Mình sẽ nhập trực tiếp token mới vào Vision Agent.
